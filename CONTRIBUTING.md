# Contributing Guidelines

Thank you for your interest in contributing to the Tankri OCR project! We welcome contributions to help improve the synthetic glyph generator, neural network architectures, and documentation.

## How to Contribute

1. **Fork the Repository**: Create a personal copy of the repository on GitHub.
2. **Setup Environment**: Clone your fork and install dependencies from `requirements.txt`.
3. **Create a Branch**: Create a new branch for your features or bugfixes (e.g. `feature/improved-augmentations`).
4. **Adhere to Code Quality**:
   * Add docstrings and type hints for new functions.
   * Format code using standard PEP8 conventions.
   * Run the verification pipeline script:
     ```bash
     python scripts/verify_pipeline.py
     ```
5. **Submit a Pull Request**: Submit your pull request to the `main` branch of the upstream repository.
